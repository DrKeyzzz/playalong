# Play-Along Changes

A band-room tool for jazz play-alongs: paste a YouTube play-along and the whole band reads along in Concert, E♭ and B♭ at once, with a big now/next chord, a solo chart, and the scale for every chord.

- Sync by hitting Space on beat 1, clicking any bar, Tap tempo, or Auto tempo (listens to the video).
- Make your own chord chart for any song, or read a chart shown in the video (needs your own Claude API key, kept only in your browser).
- Videos play in YouTube's own embedded player.

The built-in tune book is locked with a class code.

Lead sheets from [OpenBook](https://github.com/veltzer/book-openbook), for classroom use; the tunes keep their own copyrights.
Notation by [abcjs](https://github.com/paulrosen/abcjs) (MIT). Chord font: Petaluma Script by Steinberg (SIL Open Font License).
